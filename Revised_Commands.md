# Revised Commands Record for Linux Desktop

Note: export relevant paths (QNN, Android NDK, etc) before execution.

Under the project root directory:

```shell
mkdir llama3.1-8b-instruct-model
huggingface-cli download meta-llama/Llama-3.1-8B-Instruct --local-dir ./llama3.1-8b-instruct-model/
```

Then:

```shell
mkdir models
mkdir models/llama3.1-8b-instruct/
python ./tools/gguf_export.py -m ./llama3.1-8b-instruct-model/ -o models/llama3.1-8b-instruct/ --out-type q8_0
```

Now the `build_x86_64` folder will be auto-generated.

```shell
./powerserve create -m ./llama3.1-8b-instruct-model/ --exe-path ./build_x86_64/out/ -o ./models/llama3.1-8b-instruct/
```
